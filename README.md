# Baryogenesis

This repository contains all the code used to perform the calculations and generate the plots in arXiv:260X.XXXXX.  If you have any questions, please contact Saarik Kalia (skalia@uchicago.edu).

This repository contains the following:

* constraint.py: Generates Figs. 4 and 5, using results of contour.py
* contour.py: Generates contour\*.npz files, which contain data for contours in Figs. 4 and 5
* evolution.py: Generates Fig. 2
* gstar.txt: Profile for relativistic SM degrees of freedom, used in cosmological evolutions (from arXiv:1609.04979)
* yield.py: Generates Fig. 3
